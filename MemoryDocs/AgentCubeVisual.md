# AgentCubeVisual —— 代理方块视觉方案

> 目标：把代理从类人模型换成**卡通风格的悬浮魔方**，不依赖任何动画资产。

---

## 1. 为什么换

类人模型没有骨骼动画会显得笨拙而僵硬；抽象成几何体后，观众会自行脑补运动。方块悬空还顺带把「没有腿」变成了设定。

## 2. 三层结构

| 层 | 载体 | 做什么 |~~~~
|---|---|---|
| 运动层 | `PostTransformMatrix`（子物体） | 整体沉浮、静止自转、移动前倾 |
| 顶点层 | 顶点着色器 | 每个小方块绕自身中心缩放 + 沿径向外推 |
| 材质层 | toon 材质参数 | 色阶、rim 随速度变化 |

三层都不写 `LocalTransform`，A\*、ORCA、到达判定完全无感知。

## 3. 资产结构

- **一个 mesh** 装下整个魔方：N×N×N 的壳层小方块，块数 = N³ − (N−2)³
- 内部塞一个实心暗色核心，填住小方块缩缝后的透光(不确定待讨论)
- 阶数 N 是模型结构，换 N 只能换 mesh，正好当 LOD 用

## 4. 实施顺序

1. **静态方块** —— 普通 Cube 打底，验证材质与 ECS 渲染链路
2. **顶点呼吸** —— 加相位场与外推，先不管整体运动
3. **运动层** —— 沉浮、静止自转、移动前倾
4. **材质反应** —— 色阶与 rim 跟速度
5. **压测** —— 几百个代理 + 阴影

每步都可独立验收，出问题范围小。

## 5. 边界（明确不做）

- 不做 VAT 顶点动画贴图
- 不做骨骼 / Animator / SkinnedMeshRenderer
- 不做半透明、发光、泛光（卡通语言不需要，且会带来 overdraw）
- 不做小方块级别的物理或碰撞

## 6. 待定

- **N 取几** —— 球面波要够多半径层次才看得出涟漪，但小尺寸下又看不出分块，需上屏对比
- 方块尺寸与 `Agent.Radius` 的对应关系

3. 外推幅度：可调
4. 波速：可调
5. 抖动：可调
